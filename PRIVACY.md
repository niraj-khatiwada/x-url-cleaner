# X URL Cleaner privacy policy

Last updated: October 30, 2026

X URL Cleaner removes query parameters from X and Twitter post links. All link processing takes place on your device.

## Links and clipboard

The extension processes post URLs passed to supported copy actions on X/Twitter, or links you manually paste into its popup. It writes the cleaned URL to your clipboard when copying. It does not read the system clipboard automatically, save a link history, or send copied or pasted links to a server. Popup input is held in memory while the popup is open.

## Website access

Automatic cleaning runs only on the HTTPS X/Twitter hosts declared in the extension manifest. The extension checks supported tab URLs to display an active or faded toolbar icon. It does not save your browsing history or transmit tab information.

## Collection, sharing, and services

The extension has no analytics, advertising, user accounts, remote executable code, or external backend. It does not collect or transmit personal data, sell data, or share link contents with third parties. Requests for its own bundled icon files stay within the installed extension.

Your browser, X/Twitter, and any extension store you use have their own privacy practices, which are separate from this extension.

## Questions

You can report an issue or ask a question through the [project's GitHub issues](https://github.com/niraj-khatiwada/x-url-cleaner/issues). Information you voluntarily post there is handled by GitHub and may be public. Do not include private links or other sensitive information in a public issue.
